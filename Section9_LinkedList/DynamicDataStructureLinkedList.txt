Array is of a fixed size. Whenever you are creating an array and later on you cannot increase or decrease the size of an array.
Why fix size the problem? Unless we are sure that we are going to store some number of elements. If we know the size, the number of elements, then we can create an array of that particular size.
If we don't know how many elements we are going to store during the runtime of a program, then we cannot decide the size of an array. If we take some random size then that size may be either insufficient or it may be excess
