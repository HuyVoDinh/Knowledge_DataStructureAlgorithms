How the height of a tree is balanced?
It is balanced using balance factor. 
Balance factor = height of left subtree - height of right subtree.
Balance factor which calculate on every node of a binary search tree, call it as AVL tree. 
On every node we calculate this and the balance factor of every node must be either {-1,0,1}. It should be any one of these. These are valid balance factors. 
bf = |hl - hr| <= 1 -> balance
if bf = |hl - hr > 1 -> imbalance

In AVL tree, every node should be balanced. If any one node is imbalance, then say tree is imbalance.
