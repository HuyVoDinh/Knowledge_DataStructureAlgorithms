Type func(param)
{
    if (base condition)
    {
        func(param);
    }
}
Recursion is function is calling itself. So if a function is calling itself, then it is called recursive function.
Base condition is there so there must be some base condition that will terminate recursion. Otherwise it will go in to infinite calling. 
Inside recursive function, there must be some condition which will make the recursion stop terminate. 

void func(int n)
{
    if (n>0)
    {
        // cout << n << endl;
        func(n-1);
        //  cout << n << endl;
    }
}

void main()
{
    int x = 3;
    func(x); 
}

func(3) -> func(2) -> func(1) -> func(0) -> go back to the previous function and come out afterwards.
